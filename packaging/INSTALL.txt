LapCat2A install, remove and use (works fully offline)
=======================================================

What you get: one VST3 effect plugin, LapCat2A (an optical leveling amplifier). Put it on an audio track.
It reports 30 samples of latency to your DAW (the 4x oversampling), so the host lines the tracks up.
This is a TEST BUILD: it has not been tried on real Windows, macOS or Linux hosts yet.

Windows
  Run windows\LapCat2A-Setup.exe. It installs the VST3 plugin for your DAW
  (C:\Program Files\Common Files\VST3, fixed location, all users) and the manual
  (C:\Program Files\Studio 87\LapCat2A, the folder the installer asks about).
  Windows may show a blue "unknown publisher" screen because the installer is not signed
  (signing costs money; the plugin is free): click "More info", then "Run anyway".
  Remove: Settings > Apps > LapCat2A > Uninstall. It asks if you also want your saved presets deleted
  (default is No, so they stay).

macOS
  Open macos\LapCat2A-macOS.pkg. It installs the VST3 plugin, the manual and "Uninstall LapCat2A".
  The installer is not notarized: if macOS blocks it, open System Settings > Privacy & Security and choose "Open Anyway".
  Remove: open "Uninstall LapCat2A" in the Applications folder. It asks if you also want your saved presets deleted
  (default is Keep).

Linux, DAW installed as a Flatpak (for example Bitwig, Reaper or Ardour from Flathub)
  1. Your DAW should use the org.freedesktop.Platform 25.08 runtime (check with: flatpak info <DAW id>, Runtime line).
  2. Install the file from the linux folder:
       flatpak install --user linux/LapCat2A-flatpak-25.08.flatpak
  3. Restart the DAW and rescan plugins.
  Remove: flatpak uninstall --user org.freedesktop.LinuxAudio.Plugins.LapCat2A

Linux, DAW installed natively
  Extract linux/LapCat2A-linux-vst3.tar.gz into ~/.vst3  (create the folder if needed), then rescan plugins.
  Remove: delete the LapCat2A.vst3 folder from ~/.vst3.

Your saved presets (kept on remove unless you choose to delete them)
  Windows : %APPDATA%\Studio 87\LapCat2A\presets
  macOS   : ~/Library/Application Support/Studio 87/LapCat2A/presets
  Linux   : ~/.local/share/Studio 87/LapCat2A/presets  (a Flatpak DAW keeps its own copy under ~/.var/app/<DAW id>/data/)
  To delete them yourself, remove the Studio 87/LapCat2A folder at that place.

Manual: LapCat2A-manual.pdf (every control, the interface tour and what is measured).
Checksums: SHA256SUMS.
